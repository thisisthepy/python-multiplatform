FAQ

Is it published on Maven Central?Maven Central 에 배포되어 있나?

Not yet. Build from source until a release is announced.아직 아니다. 릴리스가 공지될 때까지 소스에서 빌드한다.

Which Python version?어떤 Python 버전인가?

CPython 3.14 today (pythonVersion in gradle.properties). Free-threaded builds can be selected with -PpythonFreeThreaded=true; this works on desktop only (236 tests, 0 failures); Android and iOS have no free-threaded prebuilts.현재 CPython 3.14 다 (gradle.properties 의 pythonVersion). free-threaded 빌드는 -PpythonFreeThreaded=true 로 고를 수 있고, desktop 에서만 동작하며(236 테스트 0 실패) Android/iOS 에는 free-threaded 프리빌트가 없다.

Do C extensions work?C 확장이 동작하나?

Yes, in principle: this is CPython itself, not a re-implementation. Each extension still has to be built for each target platform.원리적으로 그렇다. 재구현이 아니라 CPython 그 자체이기 때문이다. 다만 확장마다 타깃 플랫폼별로 빌드되어 있어야 한다.

Why not reflection?왜 리플렉션을 쓰지 않나?

Kotlin/Native has effectively none, and a GraalVM native image only contains what was known at build time. A generated table works in both.Kotlin/Native 에는 사실상 없고, GraalVM 네이티브 이미지에는 빌드 타임에 알려진 것만 들어간다. 생성된 테이블은 둘 다에서 동작한다.

Why is androidx not renamed to something Pythonic?왜 androidx 를 파이써닉한 이름으로 바꾸지 않나?

Because a Kotlin name in Python should mean the Kotlin thing. Pythonic packages are written on top, under their own names, in pythonx-compose.Python 에서 Kotlin 이름은 Kotlin 의 그것을 뜻해야 하기 때문이다. 파이써닉한 패키지는 그 위에, 자기 이름으로, pythonx-compose 에서 작성한다.
