Use Python from KotlinKotlin 에서 Python 쓰기

Start CPython, move values across, and treat Python errors as Kotlin exceptions.CPython 을 시작하고, 값을 건네고, Python 오류를 Kotlin 예외로 다룬다.

01Start the interpreter인터프리터 시작

Python3.initialize() is idempotent. On Android, call PythonBootstrap.initialize(context) instead (see platform setup).Python3.initialize() 는 여러 번 불러도 된다. Android 에서는 대신 PythonBootstrap.initialize(context) 를 부른다 (플랫폼별 준비 참고).

import python.multiplatform.ffi.PyObject
import python.multiplatform.ffi.Python3
import python.multiplatform.ffi.types.basic.PyInt
import python.multiplatform.ffi.types.collections.PyList

fun main() {
    Python3.initialize()

    val numbers = PyList.fromList(listOf(2L, 3L, 5L, 7L, 11L).map { PyInt.from(it) })
    Python3.import("__main__").setAttr("kotlin_numbers", numbers)

    val globals = Python3.import("__main__").dict
    val result: PyObject = Python3.eval("sum(kotlin_numbers) * 2", 258, globals, globals)
    println("${result.Type.name}: $result")   // int: 56
}

02Statements and expressions문장과 식

Python3.exec(source) runs statements; Python3.eval(expr, mode, globals, locals) returns a PyObject; Python3.import(name) returns a PyModule.Python3.exec(source) 는 문장을 실행하고, Python3.eval(expr, mode, globals, locals) 는 PyObject 를 돌려주며, Python3.import(name) 은 PyModule 을 돌려준다.

03Collections are Kotlin collections컬렉션은 Kotlin 컬렉션이다

PyList implements MutableList, PyDict implements MutableMap, PySet implements MutableSet, PyTuple implements List. Build them with fromList, fromMap, fromSet.PyList 는 MutableList, PyDict 는 MutableMap, PySet 은 MutableSet, PyTuple 은 List 를 구현한다. fromList, fromMap, fromSet 으로 만든다.

04Errors오류

A Python exception raised by exec or eval is thrown as PyException, carrying the real exception type and message. exec is built on PyRun_String rather than PyRun_SimpleString, which would print and clear the error before Kotlin could see it.exec 나 eval 에서 일어난 Python 예외는 실제 예외 타입과 메시지를 담은 PyException 으로 던져진다. exec 는 PyRun_SimpleString 이 아니라 PyRun_String 위에 있다, 앞의 것은 Kotlin 이 보기 전에 오류를 출력하고 지워 버린다.
