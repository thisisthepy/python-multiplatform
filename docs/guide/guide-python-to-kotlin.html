Use Kotlin from PythonPython 에서 Kotlin 쓰기

Write a Kotlin class; import it from Python under its Kotlin package name.Kotlin 클래스를 쓰고, Python 에서 그 Kotlin 패키지 이름으로 import 한다.

01Write KotlinKotlin 작성

Every public declaration is exposed. Annotate with @PythonInternal to keep one out.모든 public 선언이 노출된다. 빼고 싶으면 @PythonInternal 을 붙인다.

package org.thisisthepy.python.multiplatform.demo.bindings

class Greeter(subject: String) {
    var subject: String = subject
    var greetings: Long = 0
        private set

    fun greet(times: Long): String { /* ... */ }
    suspend fun greetNow(times: Long): String = greet(times)
}

02Write PythonPython 작성

from org.thisisthepy.python.multiplatform.demo.bindings import Greeter

g = Greeter('Kotlin')    # constructs the Kotlin object
g.greet(2)               # calls the Kotlin method
g.subject = 'Python'     # property setter
g.greetings = 99         # AttributeError: the Kotlin setter is private

async def main():
    return await g.greetNow(1)   # a Kotlin suspend fun, awaited

Constructors, methods, properties, companion members and object declarations all work. A property with a private set is read-only from Python. Annotation classes and generic declarations are not exposed.생성자, 메서드, 프로퍼티, companion 멤버, object 선언이 모두 동작한다. private set 인 프로퍼티는 Python 에서 읽기 전용이다. 애노테이션 클래스와 제네릭 선언은 노출되지 않는다.

03Suspend functionssuspend 함수

A suspend fun is awaitable. If it never suspends it completes immediately; if it does, it is resumed from a Kotlin thread, and cancelling the Python future cancels the coroutine. On wasm, which has no threads, only the synchronous surface is available.suspend fun 은 await 할 수 있다. 중단하지 않으면 바로 끝나고, 중단하면 Kotlin 스레드에서 재개되며, Python future 를 취소하면 코루틴도 취소된다. 스레드가 없는 wasm 에서는 동기 표면만 쓸 수 있다.

04Extension functions확장 함수

A Kotlin extension function appears in Python as a method on its receiver, so chains read naturally: Modifier.padding(16).size(24).Kotlin 확장 함수는 Python 에서 수신 객체의 메서드로 보인다. 그래서 체인이 자연스럽게 읽힌다: Modifier.padding(16).size(24).

Status: partial. Asserted through the adapter and the artifact walker; not yet for KSP-generated proxies.상태: 부분. 어댑터와 아티팩트 워커로는 검증되었고, KSP 생성 프록시는 아직이다.

05Native images네이티브 이미지

Because the table is generated, nothing needs reflection registration: the sample's upcalls run in a GraalVM native image built with Liberica NIK.테이블을 생성하므로 리플렉션 등록이 필요 없다. 샘플의 업콜은 Liberica NIK 로 만든 GraalVM 네이티브 이미지에서 동작한다.
