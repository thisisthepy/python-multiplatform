Ecosystem생태계

One boundary, several projects하나의 경계, 여러 프로젝트

python-multiplatform owns the language boundary. The repositories around it build on it.python-multiplatform 은 언어 경계를 맡는다. 주변 저장소들이 그 위에 선다.

python-multiplatform

The language boundary: embedded CPython, object model, upcalls. You are here.언어 경계: 임베딩된 CPython, 객체 모델, 업콜. 지금 보는 곳.

pythonx-compose

Real Python packages that import the Compose modules and make them Pythonic.Compose 모듈을 가져와 파이써닉하게 만드는 실제 Python 패키지.

toolchain

The Gradle vocabulary for building Python apps.Python 앱 빌드를 위한 Gradle 어휘.

pypackpack

Python acquisition, dependency resolution, cross-compilation and bundling.Python 취득, 의존성 해석, 교차 컴파일, 번들링.

torchnative

The real PyTorch ecosystem on device.기기 위의 진짜 PyTorch 생태계.

Gemstone

An independent project planning to adopt python-multiplatform.python-multiplatform 채택을 계획 중인 독립 프로젝트.

Division of labour: pypackpack does the work, toolchain speaks Gradle, python-multiplatform owns the language boundary.역할 분담: pypackpack 이 일을 하고, toolchain 이 Gradle 을 말하며, python-multiplatform 이 언어 경계를 맡는다.
