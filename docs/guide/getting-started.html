Getting started시작하기

From clone to a running sample클론부터 샘플 실행까지

No release is published yet, so you build from source. The sample app is the shortest path to seeing both directions work.아직 배포된 릴리스가 없으므로 소스에서 빌드한다. 두 방향이 동작하는 것을 보는 가장 짧은 길은 샘플 앱이다.

01Requirements준비물

  • A JDK for Gradle, and Git.Gradle 용 JDK 와 Git.
  • The Android SDK (with ANDROID_HOME set) for Android targets.Android 타깃에는 Android SDK (ANDROID_HOME 설정).
  • macOS with Xcode for iOS targets.iOS 타깃에는 Xcode 가 있는 macOS.

You do not install Python: Gradle downloads the CPython build for each platform, verifies it, and extracts it. The version is set by pythonVersion in gradle.properties.Python 을 설치하지 않는다. Gradle 이 플랫폼마다 CPython 빌드를 내려받아 검증하고 푼다. 버전은 gradle.properties 의 pythonVersion 으로 정한다.

02Clone and run클론하고 실행하기

git clone https://github.com/thisisthepy/python-multiplatform
cd python-multiplatform
./gradlew :sample:run

The desktop sample starts CPython, publishes a Kotlin-built list into Python, evaluates an expression, and drives a Kotlin class from Python.데스크톱 샘플은 CPython 을 시작하고, Kotlin 에서 만든 리스트를 Python 에 게시하고, 식을 평가하고, Python 에서 Kotlin 클래스를 움직인다.

03Your first call첫 호출

import python.multiplatform.ffi.PyObject
import python.multiplatform.ffi.Python3
import python.multiplatform.ffi.types.basic.PyInt
import python.multiplatform.ffi.types.collections.PyList

fun main() {
    Python3.initialize()

    val numbers = PyList.fromList(listOf(2L, 3L, 5L, 7L, 11L).map { PyInt.from(it) })
    Python3.import("__main__").setAttr("kotlin_numbers", numbers)

    val globals = Python3.import("__main__").dict
    val result: PyObject = Python3.eval("sum(kotlin_numbers) * 2", 258, globals, globals)
    println("${result.Type.name}: $result")   // int: 56
}

There is no close() in that code, and none is missing: every wrapper releases its Python reference when the Kotlin object is collected.위 코드에는 close() 가 없고, 빠진 것도 아니다. 모든 래퍼는 Kotlin 객체가 수거될 때 Python 참조를 놓는다.

04Verify a change변경 검증하기

./gradlew :python-multiplatform:compileKotlinAndroidNativeArm64 --console=plain > .tmp/build.log 2>&1; echo "EXIT=$?"
./gradlew :python-multiplatform:desktopTest --rerun --console=plain > .tmp/test.log 2>&1; echo "EXIT=$?"
./gradlew :ksp-fixtures:app:desktopTest --rerun
./gradlew :ksp-fixtures:compose:desktopTest --rerun
./gradlew :ksp-fixtures:artifact:desktopTest --rerun

Run the fixture modules one by one: a single invocation has hidden an ordering dependency before. Read exit codes from a file, never through a pipe.픽스처 모듈은 하나씩 따로 돌린다. 한 번에 돌리면 순서 의존성이 가려진 적이 있다. 종료 코드는 파이프가 아니라 파일에서 읽는다.
